- "Boshlash" tugmasidan keyin asosiy platforma ochiladi.
- Compost bo‘limi olib tashlandi.
- Uning o‘rniga "O‘tin & Bog‘ yog‘ochi" bo‘limi qo‘shildi.
- Uy, hovli va bog‘lardan kesilgan quruq o‘tin, shox-shabba, mevali daraxt o‘tini va tandir o‘tini uchun realistik e’lonlar qo‘shildi.

- Platforma positioning matni kuchaytirildi.

## Ishga tushirish
1. ZIP faylni oching.
2. Papkani VS Code’da oching.
3. `index.html` faylini Live Server orqali ishga tushiring.
